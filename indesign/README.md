# InDesign Importer

Turn AI Yearbook session data into an editable Adobe InDesign 2024+ document.

## Quick Start

### 1. Generate the bundle (Terminal)

```bash
# List available sessions
npm run export:indesign -- --list

# Export every session as one bundle
npm run export:indesign -- --all --batch "fall-2025-yearbook"

# Export specific sessions in a specific order
npm run export:indesign -- --sessions abc-123,def-456 --batch "athletics"
```

The CLI prints the bundle folder path. The folder contains:

- `manifest.json` — master index with document setup + spread list
- `spreads/` — one JSON file per spread (layout + metadata)
- `links/` — JPEG photos InDesign will link to
- `indesign-import-log.txt` — written after import (warnings + errors)

### 2. Install the script in InDesign (once)

In InDesign:

1. **Window → Utilities → Scripts**
2. Right-click "User" in the Scripts panel → **Reveal in Finder**
3. Drag the `indesign/` folder from this repo into the revealed folder
4. The Scripts panel now shows `indesign/ImportYearbook.jsx`

### 3. Run the import

1. Make sure no document is open (the script creates a new one)
2. Double-click `ImportYearbook.jsx` in the Scripts panel
3. When prompted, choose the bundle folder generated by the CLI
4. Wait for the summary alert — it'll list errors, missing fonts, and where the file was saved
5. The `.indd` is saved in the bundle folder as `yearbook-import.indd`

## What the script does

For each spread in the bundle:

- Adds the correct number of pages (1 for `page`, 2 for `spread`)
- Creates a named layer ("Spread N - {section}") for easy navigation
- Places photos as linked JPEGs with the correct frame, fill-frame-proportional fitting, and cropX/cropY offset
- Applies paragraph styles to every text element (`[Yearbook] Page Title`, `[Yearbook] Body Copy`, etc.)
- Uses CMYK swatches: `YB Primary Purple`, `YB Text Dark`, `YB Text Medium`, `YB Text Light`
- For pageTitle elements with a `themeWord`, applies the `[Yearbook] Theme Word` character style (italic + purple) to just that span
- For body copy and roster elements with `columns > 1`, configures text frame columns
- Black-and-white photos use a pre-generated grayscale variant from the bundle (`_bw.jpg`)

## Editing afterward

Because every text element uses a named paragraph style, you can change the look of every yearbook page by editing the style once. Open **Window → Styles → Paragraph Styles**, edit `[Yearbook] Body Copy` font/size/color, and every body copy on every page updates.

Photos are **linked** (not embedded). To swap a photo, replace the file in the bundle's `links/` folder and use **Window → Links** to relink.

The layers panel groups every spread into its own layer, so to fine-tune one spread you can:

1. Open Layers panel (F7)
2. Click the spread's layer to make it active
3. Hide other spread layers to focus

## Required fonts

The script expects these (Google Fonts — all free):

- Playfair Display
- Source Sans Pro
- Dancing Script
- Oswald

If any are missing, the script warns at startup and InDesign substitutes. Install the fonts via Adobe Fonts (Creative Cloud → Fonts → search and activate) or download from Google Fonts.

## Troubleshooting

- **"manifest.json not found"** — You picked the wrong folder. Pick the bundle folder itself (the one named `{batchName}-{timestamp}`), not its parent.
- **"Failed to create document"** — Close all InDesign documents and try again, or check the log file.
- **Photos appear off-center** — `cropX`/`cropY` interprets 50% as center (matches CSS `object-position`). If a photo is consistently cropped wrong, check the source `cropX`/`cropY` values in the spread JSON.
- **Text styles look wrong** — Confirm the required fonts are installed. The script applies styles by name, but InDesign substitutes if the font isn't available.
- **B&W photos render in color** — Make sure the bundle's `links/` folder has a matching `_bw.jpg` file. The exporter only generates these when a photo is flagged `blackAndWhite: true` in the layout.

## Architecture

```
bundle/
├── manifest.json              ← Read first; describes everything
├── spreads/
│   └── 001-name.json          ← Per-spread layout JSON
└── links/
    └── 001-photo-0.jpg        ← Photos referenced by linkPath
    └── 001-photo-0_bw.jpg     ← B&W variant when needed

indesign/
├── ImportYearbook.jsx         ← Main entry point
└── lib/
    ├── json2.js               ← JSON polyfill for old ExtendScript
    ├── utils.jsx              ← inches→points, logging, font check
    ├── colors.jsx             ← Swatches + hex→CMYK
    ├── doc.jsx                ← Document creation, page addition
    ├── styles.jsx             ← Paragraph + character style setup
    ├── photo.jsx              ← Photo placement + cropX/Y → frame fitting
    └── elements.jsx           ← Dispatch table: el.type → renderer
```

## Editing the renderer

To add a new element type or change how an existing one renders:

1. Edit `indesign/lib/elements.jsx`
2. Add a `renderXxx()` function
3. Register it in the `ELEMENT_RENDERERS` dispatch table at the bottom

The schema reference is `src/services/htmlRenderer.js` in the main codebase — every `renderXxx` there describes which fields each element type uses.
